# Goal Tracker

An Obsidian plugin for setting and tracking goals with quarterly reviews, milestones, progress notes, and outcome logging.

## Features

- **New Goal** — Create a goal note with title, category (personal/career/health/financial/learning), target date, motivation, and success criteria
- **Add Milestone** — Attach milestones with due dates to any goal
- **Log Progress** — Record a progress note and update the % complete slider (0–100) for any goal
- **Quarterly Review** — Generate a structured review note (what worked, what didn't, goals to carry forward)
- **Goals Sidebar** — Live sidebar listing all goals with category badge, % progress bar, and target date

## Usage

Open the command palette (`Ctrl/Cmd+P`) and search for:
- `Goal Tracker: New Goal`
- `Goal Tracker: Add Milestone`
- `Goal Tracker: Log Progress`
- `Goal Tracker: Quarterly Review`
- `Goal Tracker: Open Goal Tracker Sidebar`

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Goals Folder | `Goals` | Folder where all goal notes are stored |
